# Hình minh họa (mục tiêu, dụng cụ bếp)

PNG ở đây được SINH từ SVG nguồn ở `docs/research/illustrations/` (Research sở hữu) bằng `python tools/svg_to_png.py`.
Đừng sửa PNG bằng tay: sửa SVG rồi chạy lại script. Bố cục `<tên>.png` (1x), `2.0x/`, `3.0x/` là bố cục ảnh nhiều độ phân giải của Flutter.

Nguồn và giấy phép từng hình: xem `docs/research/illustrations-licenses.md`. Tóm tắt:

| Hình | Nguồn | Giấy phép |
|---|---|---|
| `goal-giam-mo` | Lucide `flame` (lucide-static 1.73.0), https://lucide.dev | ISC |
| `goal-tang-co` | Lucide `biceps-flexed` (lucide-static 1.73.0), https://lucide.dev | ISC |
| `goal-giu-can`, `dungcu-*` (7 hình) | Tự vẽ cho dự án | Thuộc dự án, không cần ghi công trong giao diện |

Giấy phép ISC: cho phép dùng, sao chép, sửa đổi và phân phối (kể cả thương mại) với điều kiện giữ thông báo bản quyền;
dòng bản quyền của Lucide nằm trong chính file SVG nguồn.
